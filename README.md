# API Todo en Python

Cette API permet de gérer une liste de tâches (todo).

## Fonctionnalités
- Créer une tâche
- Lire toutes les tâches
- Mettre à jour une tâche
- Supprimer une tâche
- Lire une tâche par ID

## Installation
```bash
pip install -r requirements.txt
```

## Lancement
```bash
python app.py
```

## Tests
```bash
pytest tests/test_app.py
```
